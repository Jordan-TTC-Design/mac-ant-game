# 手機版版面重新規劃（規劃，2026-10-17）

> 使用者：「幫我手機版再重新規劃一下 ui 編排，照現在功能規劃 toolbar 以及各大功能版面，要更好用、ux 要好。」
> 調查：28 頁全頁截圖與清單（每頁捲幾屏、從哪進、回到哪）。

## 0. 現在的問題

1. **下方工具列跟內容對不上**
   - 番茄鐘佔一整個分頁，但它只有一屏，大部分時間閒著。
   - 最深的大世界、公會反而沒有分頁：大世界只能從首頁卡片或營地標題的 🗺️ 進去。
   - 首頁 7 張卡片裡有 4 張跟分頁重複。
2. **工具列時有時無**
   - 名冊、工坊、動態有工具列；任務、領地、大世界、天賦、戰報、排行、公會各頁、捏臉、回報都沒有。
   - 從營地 → 領地 → 格子 → 地圖 → 戰報，走一步工具列就不見了，只能一路按返回。
3. **返回鍵寫死**
   - 從首頁進排行榜，按返回卻回到大世界。
   - 大世界的返回永遠回營地。
   - 有兩種返回鍵樣式：「← 營地」小膠囊和光一個「‹」。
4. **頁面太長**
   - 工坊 5.5 屏、營地 5.2 屏（12 塊以上的面板疊成一欄）、動態 4.6 屏、名冊 4 屏、城鎮格子 4.1 屏。
   - 工坊和名冊的入口在營地最底下。
   - 天賦頁開頭 17 行加成說明，把天賦樹擠到下面。
5. **功能分散、重複**
   - 動態在營地和動態頁各一份。
   - 格子的操作一半在地圖的卡片（派人、撤回、蓋巢、搬營地），一半在領地頁（建築、自動調人）。
   - 排行榜有兩個入口。
6. **找不到**
   - 天賦只有大世界的 ⭐ 能進。
   - 任務、領地、動態藏在營地標題上沒有字的 📜🏰🕘 圖示裡。
   - 設定沒有「登出」。
   - 回報問題在首頁最底下。
7. **小目標、擠**
   - 營地標題的 4 個圖示把標題擠成兩行。
   - 大世界的副標題三行。
   - 地圖格子卡片 6 個按鈕擠成兩排。
   - 天賦樹的分頁、回報的篩選列在右邊被截掉。
   - 便利貼的「新增」按鈕在畫面外。
8. **紅點太少**：只有首頁（Claude）和好友有紅點。可領的任務、來訪者、商人、敵軍來襲、沒點的天賦、公會邀請都沒提示。

## 1. 原則

- **工具列 = 五個大地方**，全部的主要頁面都看得到工具列；只有「全螢幕」的頁面（公會大廳、聊天、便利貼編輯）才藏起來。
- **每個大地方頂端一條子分頁**：同一個大地方裡的頁面左右切換，不用一層一層往下鑽。最多兩層：大地方 → 子分頁 → 單一東西（一格、一封戰報、一則回報）。
- **返回照歷史**：從哪來就回哪；直接打開網址時才回到那個大地方的首頁。
- **一頁一件事**：一屏半以內看得到重點，長的內容收起來或拆到子分頁。
- **該做的事浮上來**：每個大地方頂端一張「現在可以做」卡片，工具列也掛紅點。

## 3. 共用的頁首

```
┌─────────────────────────────────┐
│ ‹ 營地    哥布林營地      [任務 3]│  ← 返回（照歷史）・標題一行・右邊最多兩個「有字」的按鈕
│ 296 隻・下一隻 1:22              │  ← 副標題一行，太長就截斷
├─────────────────────────────────┤
│ 總覽 建設 工坊 名冊 任務 動態 →  │  ← 子分頁，捲到頁面下面時黏在頂端，可以左右滑
└─────────────────────────────────┘
```

- 一個 `AppHeader` 元件：所有頁面用同一種返回鍵（「‹ 上一頁的名字」）。
- 一個 `SubTabs` 元件：大地方裡的子分頁，可以橫向滑，選到的那個自動捲進畫面裡（天賦樹、回報篩選也用它，不會再被截掉）。
- 返回鍵：有上一頁就回上一頁，沒有才回這個大地方的首頁。

## 5. 做的順序

1. **骨架**（改動最大、最有感）：
   - 新的工具列和紅點。
   - `AppHeader`、`SubTabs`、照歷史的返回鍵。
   - 「今天」頁。
   - 夥伴頁。
   - 所有主要頁面都有工具列。
2. **營地**：子分頁、總覽、搬出建設頁、工坊的建議卡片、名冊自動載入。
3. **大世界**：子分頁、地圖撐滿、格子卡片兩個按鈕、格子頁三個小分頁、天賦收合、戰報頁。
   - 這一步會動到 `WorldMap.vue` 和領地頁，要先跟負責大世界的工作階段說好。
4. **公會與細節**：公會首頁卡片、捐獻 ±、成員的「⋯」、設定的登出、便利貼的儲存鍵。

每一步做完都用截圖程式拍一次 28 頁，確認沒有東西被截掉、每頁的長度有變短。
